# ADR 0011: Branch value, semantic opportunities and auditable evidence

Accepted, 2026-10-22.

Replace whole-run novelty counters with per-branch reviewed marginal-value observations. Never use an exhausted branch to cancel an unexplored sibling. Large branch cohorts are processed independently; small residuals wait for frontier/page-boundary completion and do not justify stopping unrelated branches.

Use existing cohort reasoning and critique to relate recommendations to a persistent opportunity catalog. NEW and justified MEANINGFUL_VARIANT decisions can create briefs; ADDITIONAL_EVIDENCE merges support without another generation/review pair. Canonical identity is independent of title wording, prices and citation changes.

Persist worker scheduling projections separately from the run aggregate. Workers query due IDs, mutate explicit stage transitions and save only actual changes. Known waits are indexed; unchanged polls and future weekly checks do not rewrite large JSON. Recovery queries only interrupted aggregates.

Preserve source/context evidence and exact model inputs alongside decisions. Archive a frozen complete bundle through an idempotent outbox so a retry cannot silently use changed source data. Source records are sanitized public facts, not reviewer/account identifiers.

Idea-to-Product owns specification detail, not business-opportunity selection. Preserve buyer/use intent, independently choose exact contents, and provide verifiable file-level QA criteria and explicit readiness. Retain substantive critique rather than replacing quality checks with JSON presence tests.

Research clearing is an explicit maintenance action, not routine startup. Each service owns its purge allowlist and preserves non-business operational projections. Historical usage/rate ledgers are never reset. New OpenAI allowances require their own authorization record and explicit cap; enabling paid routing is separate.
