# Fresh Halloween cohort: deterministic test run

## Scope and deletion

The six previously fetched response/observation JSON files were deleted before this collection. Code, synthetic test fixtures and historical documentation were preserved. The old discovery directory now contains only its operational request ledger and lock; deleting research did not reset usage counters. The deleted research payloads were not archived by this operation and are not recoverable through Git.

This run collected 1000 unique actual Etsy search listings for `halloween printable`, ordered by score, ten pages of 100, with offsets 0 through 900. There was no duplication, padding, model-generated input or reuse of the earlier four samples. The cohort was completed at 2026-10-21 16:02:47 UTC.

The 1000-item set includes physical matches. Digital metrics below use only its 945 downloads, rather than silently relabeling all 1000 as digital. This is a ranked convenience sample, not a representative estimate of market demand.

## Interpretation for cheap experiments

The 902 unflagged downloads provide examples for reusable, low-touch templates; the flags alone do not establish actual labor, profitability, rights, unmet needs or whether comparable experiments will sell. The 43 flagged listings are candidates for reusable automation assessment, not automatic rejection.

The deterministic candidate queue orders automation hints with stable-ID ties. It does not rank expected revenue or require proof of demand before publication. No sales, recurring receipts, conversion rate, probability of success, or dollar operating cost was inferred from views/favorites.

A practical next experiment should select a reusable printable format, cap money and manual minutes, and learn from published performance. Extensive extra research is justified only if its expected decision benefit exceeds its cost. Actual publication and asset generation are outside this run.
